# 安装指引（首次打开被系统拦截怎么办）

本应用目前**未购买代码签名证书**，所以 Windows / macOS 第一次打开会弹出"未知发布者 / 无法验证开发者"的安全提示。这是未签名应用的正常现象，**不是病毒**。按下面步骤放行一次即可，之后正常使用。

> 安全提醒：请只从我们提供的官方 Release 页面下载安装包。

---

## Windows（`.exe` 或 `.msi`）

1. 双击安装包，若出现蓝色窗口 **"Windows 已保护你的电脑 / Windows protected your PC"**：
2. 点窗口里的 **"更多信息 / More info"**。
3. 再点下方出现的 **"仍要运行 / Run anyway"**。
4. 正常完成安装。

如果是 360 / 电脑管家等国产安全软件报"未知程序"：选择 **信任 / 允许运行 / 加入白名单**。

---

## macOS（`.dmg`，Apple 芯片）

把 App 拖进"应用程序"后，第一次打开：

**方法一（推荐）**
1. 在"应用程序"里**右键点击** WB AutoList → 选 **"打开"**。
2. 弹窗里再点一次 **"打开"**。

**方法二（若上面没有"打开"选项，多见于较新 macOS）**
1. 双击打开一次（会被拦下，提示"无法打开"）。
2. 打开 **系统设置 → 隐私与安全性**，滑到底部会看到"已阻止 WB AutoList…"，点 **"仍要打开 / Open Anyway"**。
3. 再打开一次 App，确认 **"打开"**。

> 若提示 **"已损坏，应移到废纸篓"**：在"终端"执行（把路径换成实际位置）：
> ```
> xattr -dr com.apple.quarantine "/Applications/WB AutoList.app"
> ```
> 然后重新用"方法一"打开。

---

## 为什么会这样 / 以后会消除吗

- 操作系统对"没有付费证书签名"的应用一律先拦一道，签名证书是按年/按月付费的（macOS 公证约 $99/年；Windows 可用 Azure Trusted Signing 约 $10/月）。
- 放行是**一次性**的——同一台电脑之后打开不再提示。
- 若后续购买签名，这些提示会自动消失，安装包无需你改动。
